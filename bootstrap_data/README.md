# Заглушка для первого деплоя на Amvera

Amvera не даёт загрузить папку **Data**, пока приложение хотя бы раз не запустится.
Эти файлы копируются в `/app/data` при старте, если индекс ещё не загружен.

В `amvera.yaml` задано `persistenceMount: /app/data` — папка Data в панели Amvera
монтируется прямо в `data/` проекта.

После загрузки реального датасета в Amvera → Репозиторий → **Data** перезапустите бот.
Заглушка заменится, когда появится `index/mapping.json` без `"stub": true`.
